# Cuestionario Big Five

FitRadarHR utiliza el cuestionario **IPIP** (International Personality Item Pool), un instrumento de medida de la personalidad libre de derechos y validado científicamente.

## Dos versiones disponibles

| Versión | Número de ítems | Duración estimada | Uso recomendado |
|---|---|---|---|
| **50 ítems** | 50 preguntas | ~10 minutos | Candidatos externos, primera evaluación |
| **100 ítems** | 100 preguntas | ~20 minutos | Colaboradores, movilidad interna, mayor precisión |

La versión predeterminada se define en la configuración de su organización y puede modificarse en cada envío.

## Desarrollo para la persona evaluada

1. La persona recibe un **email con un enlace seguro**
2. Consulta y acepta el **aviso de consentimiento RGPD**
3. Responde a las preguntas a su ritmo (puede retomarlo más tarde)
4. Al final, el perfil Big Five se calcula automáticamente
5. El usuario de RR. HH. o el manager recibe una notificación y puede generar el informe

!!! info "No hay respuesta buena o mala"
    El cuestionario mide rasgos de personalidad, no competencias. No hay respuesta ideal — la persona debe responder de forma espontánea y honesta.
