# Send a questionnaire link

## Access

From a person's page (candidate or employee), click **Send questionnaire** — the email is pre-filled automatically.

You can also access the form directly via **Questionnaires → Send a link**.

## Send options

| Field | Required | Description |
|---|---|---|
| Email | ✅ | The person's email |
| First/last name | If new person | Filled in if the person doesn't exist yet — they will be created automatically |
| Related position | No | Attaches the questionnaire to a position to give context to the fit in reports |
| Version | — | 50 or 100 items (50 recommended — about 10 min) |
| Language | — | FR or EN — the person can change it when opening the link |

!!! tip "Creation on the fly"
    If you enter an unknown email, FitRadarHR automatically creates the person record with the first and last name you entered. No need to go through the People section first.

!!! tip "Attaching to a position"
    By selecting a position, the candidate's profile report will display the corresponding Position Fit first. This doesn't prevent fit calculation against other positions.

## What the person receives

The email sent contains:

- A secure, unique link (not reusable)
- The estimated questionnaire duration
- A GDPR notice (data is used only for this evaluation)

!!! warning "Single-use link"
    Each link is tied to a single person and cannot be shared. If the person needs a new link (expired link, lost email), use the **Resend** button in the questionnaires dashboard.
