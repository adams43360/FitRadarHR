# Fortschritt verfolgen

## Fragebogenstatus

| Status | Bedeutung |
|---|---|
| ⏳ **Ausstehend** | Link versendet, Fragebogen nicht begonnen |
| 🔄 **Laufend** | Die Person hat begonnen, aber noch nicht abgeschlossen |
| ✅ **Abgeschlossen** | Fragebogen beendet, Big-Five-Profil berechnet |
| ⛔ **Abgelaufen** | Der Link hat sein Ablaufdatum überschritten |

## Eine Erinnerung senden

Ist der Status seit mehreren Tagen **Ausstehend**, können Sie von der Seite der Person aus eine Erinnerungs-E-Mail erneut senden. Derselbe Link wird erneut versendet (das Ablaufdatum bleibt unverändert).

## Einen laufenden Fragebogen fortsetzen

Die Person kann ihren Browser jederzeit schließen. Ihr Fortschritt wird automatisch gespeichert. Beim erneuten Öffnen des Links setzt sie dort fort, wo sie aufgehört hat.

!!! info "Vertraulichkeit der Antworten"
    Sie sehen nicht die individuellen Antworten auf die Fragen — nur die 5 dimensionalen Werte des Endprofils. Die Rohantworten werden nach der Profilberechnung gelöscht.

## Erneute Durchführung & Longitudinal-Tracking

Ein Big-Five-Profil kann sich weiterentwickeln (interne Mobilität, Rollenwechsel, mehrere Jahre zwischen zwei Bewertungen). Der Button **↻ Fragebogen erneut durchführen**, verfügbar im Profilbericht einer Person, sendet einen neuen Ausfüll-Link.

Schließt die Person diese neue Durchführung ab, wird ihr vorheriges Profil automatisch archiviert — es geht nie verloren. Der Profilbericht zeigt dann einen Abschnitt **Profilentwicklung**: eine Kurve und eine Tabelle mit den Werten jeder Dimension über die aufeinanderfolgenden Durchführungen hinweg.

!!! note
    Nur das aktuelle (neueste) Profil wird für die Fit-Berechnungen mit Stellen und Teams verwendet. Der Verlauf dient ausschließlich der Verfolgung über die Zeit.
