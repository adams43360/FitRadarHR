# Einen Fragebogenlink senden

## Zugriff

Klicken Sie auf der Seite einer Person (Kandidat oder Mitarbeitende(r)) auf **Fragebogen senden** — die E-Mail wird automatisch vorausgefüllt.

Sie können das Formular auch direkt über **Fragebögen → Link senden** aufrufen.

## Versandoptionen

| Feld | Pflichtfeld | Beschreibung |
|---|---|---|
| E-Mail | ✅ | E-Mail-Adresse der Person |
| Vor-/Nachname | Bei neuer Person | Auszufüllen, wenn die Person noch nicht existiert — sie wird automatisch angelegt |
| Zugehörige Stelle | Nein | Verknüpft den Fragebogen mit einer Stelle, um den Fit in Berichten zu kontextualisieren |
| Version | — | 50 oder 100 Items (50 empfohlen — etwa 10 Min.) |
| Sprache | — | FR oder EN — die Person kann beim Öffnen des Links wechseln |

!!! tip "Erstellung im laufenden Prozess"
    Geben Sie eine unbekannte E-Mail-Adresse ein, erstellt FitRadarHR automatisch den Personendatensatz mit dem von Ihnen angegebenen Vor- und Nachnamen. Es ist nicht nötig, vorher über den Bereich Personen zu gehen.

!!! tip "Zuordnung zu einer Stelle"
    Durch Auswahl einer Stelle zeigt der Profilbericht des Kandidaten vorrangig den entsprechenden Stellen-Fit an. Dies verhindert nicht die Fit-Berechnung für andere Stellen.

## Was die Person erhält

Die versendete E-Mail enthält:

- Einen sicheren, eindeutigen Link (nicht wiederverwendbar)
- Die geschätzte Dauer des Fragebogens
- Einen DSGVO-Hinweis (die Daten werden ausschließlich für diese Bewertung verwendet)

!!! warning "Einmal verwendbarer Link"
    Jeder Link ist einer einzigen Person zugeordnet und kann nicht geteilt werden. Benötigt die Person einen neuen Link (abgelaufener Link, verlorene E-Mail), verwenden Sie den Button **Erneut senden** im Fragebogen-Dashboard.
