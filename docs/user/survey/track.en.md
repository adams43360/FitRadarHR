# Track progress

## Questionnaire statuses

| Status | Meaning |
|---|---|
| ⏳ **Pending** | Link sent, questionnaire not started |
| 🔄 **In progress** | The person has started but not finished |
| ✅ **Completed** | Questionnaire finished, Big Five profile calculated |
| ⛔ **Expired** | The link has passed its expiration date |

## Sending a reminder

If the status has been **Pending** for several days, you can resend a reminder email from the person's page. The same link is resent (the expiration date remains unchanged).

## Resuming an in-progress questionnaire

The person can close their browser at any time. Their progress is saved automatically. Reopening the link, they resume where they left off.

!!! info "Answer confidentiality"
    You do not see individual answers to questions — only the final profile's 5 dimensional scores. Raw answers are deleted after the profile is calculated.

## Re-taking & longitudinal tracking

A Big Five profile can evolve (internal mobility, taking on a role, several years between two evaluations). The **↻ Re-take questionnaire** button, available on a person's profile report, sends a new completion link.

When the person finishes this new attempt, their previous profile is automatically archived — it is never lost. The profile report then displays a **Profile evolution** section: a chart and a table showing each dimension's scores across successive attempts.

!!! note
    Only the current (most recent) profile is used for fit calculations with positions and teams. History is used only for tracking over time.
