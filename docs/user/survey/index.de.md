# Big-Five-Fragebogen

FitRadarHR verwendet den **IPIP**-Fragebogen (International Personality Item Pool), ein lizenzfreies und wissenschaftlich validiertes Instrument zur Persönlichkeitsmessung.

## Zwei verfügbare Versionen

| Version | Anzahl Items | Geschätzte Dauer | Empfohlene Nutzung |
|---|---|---|---|
| **50 Items** | 50 Fragen | ~10 Minuten | Externe Kandidaten, Erstbewertung |
| **100 Items** | 100 Fragen | ~20 Minuten | Mitarbeitende, interne Mobilität, höhere Genauigkeit |

Die Standardversion wird in den Einstellungen Ihrer Organisation festgelegt und kann bei jedem Versand geändert werden.

## Ablauf für die bewertete Person

1. Die Person erhält eine **E-Mail mit einem sicheren Link**
2. Sie liest und akzeptiert den **DSGVO-Einwilligungshinweis**
3. Sie beantwortet die Fragen in ihrem eigenen Tempo (kann später fortgesetzt werden)
4. Am Ende wird das Big-Five-Profil automatisch berechnet
5. Die HR-Person oder Führungskraft erhält eine Benachrichtigung und kann den Bericht erstellen

!!! info "Keine richtige oder falsche Antwort"
    Der Fragebogen misst Persönlichkeitsmerkmale, keine Kompetenzen. Es gibt keine ideale Antwort — die Person sollte spontan und ehrlich antworten.
