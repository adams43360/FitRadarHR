# Big Five questionnaire

FitRadarHR uses the **IPIP** questionnaire (International Personality Item Pool), a royalty-free and scientifically validated personality measurement instrument.

## Two versions available

| Version | Number of items | Estimated duration | Recommended use |
|---|---|---|---|
| **50 items** | 50 questions | ~10 minutes | External candidates, initial evaluation |
| **100 items** | 100 questions | ~20 minutes | Employees, internal mobility, increased precision |

The default version is set in your organization's settings and can be changed for each send.

## Process for the evaluated person

1. The person receives an **email with a secure link**
2. They review and accept the **GDPR consent notice**
3. They answer the questions at their own pace (can resume later)
4. At the end, the Big Five profile is calculated automatically
5. The HR user or manager receives a notification and can generate the report

!!! info "No right or wrong answer"
    The questionnaire measures personality traits, not skills. There is no ideal answer — the person should answer spontaneously and honestly.
