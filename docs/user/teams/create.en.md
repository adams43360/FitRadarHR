# Create a team

## Access

From the dashboard or the **Teams** menu, click **New team**.

<!-- screenshot: docs/user/assets/team-create.png -->
!!! note "Screenshot coming soon"

## Form fields

| Field | Required | Description |
|---|---|---|
| Team name | ✅ | E.g.: *Product team*, *Sales EMEA* |
| Description | ❌ | Context, team's responsibilities |
| Responsible manager | ✅ | Manager or Solo type user in your organization |

## After creation

The team is created with no members. The next step is to [add members](members.md) so that Team Fit can be calculated.
