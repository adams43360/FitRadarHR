# Crear un equipo

## Acceso

Desde el panel de control o el menú **Equipos**, haga clic en **Nuevo equipo**.

<!-- screenshot: docs/user/assets/team-create.png -->
!!! note "Captura de pantalla próximamente"

## Campos del formulario

| Campo | Obligatorio | Descripción |
|---|---|---|
| Nombre del equipo | ✅ | Ej.: *Equipo de producto*, *Sales EMEA* |
| Descripción | ❌ | Contexto, misiones del equipo |
| Manager responsable | ✅ | Usuario de tipo Manager o Individual en su organización |

## Después de la creación

El equipo se crea sin miembros. El siguiente paso es [añadir miembros](members.md) para que el Fit de Equipo pueda calcularse.
