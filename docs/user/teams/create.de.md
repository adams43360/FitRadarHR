# Ein Team erstellen

## Zugriff

Klicken Sie im Dashboard oder im Menü **Teams** auf **Neues Team**.

<!-- screenshot: docs/user/assets/team-create.png -->
!!! note "Screenshot folgt in Kürze"

## Formularfelder

| Feld | Pflichtfeld | Beschreibung |
|---|---|---|
| Teamname | ✅ | z. B.: *Produktteam*, *Sales EMEA* |
| Beschreibung | ❌ | Kontext, Aufgaben des Teams |
| Verantwortliche Führungskraft | ✅ | Nutzer(in) vom Typ Manager oder Einzelperson in Ihrer Organisation |

## Nach der Erstellung

Das Team wird ohne Mitglieder erstellt. Der nächste Schritt ist, [Mitglieder hinzuzufügen](members.md), damit der Team-Fit berechnet werden kann.
