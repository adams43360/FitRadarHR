# Teammitglieder verwalten

## Ein Mitglied hinzufügen

Ein Mitglied muss eine **Person sein, die ihren Big-Five-Fragebogen abgeschlossen hat**. Ohne Big-Five-Profil kann die Person nicht in die Team-Fit-Berechnung einbezogen werden.

1. Öffnen Sie die Teamseite
2. Klicken Sie auf **Mitglied hinzufügen**
3. Suchen Sie die Person nach Name oder E-Mail
4. Bestätigen Sie das Hinzufügen

## Ein Mitglied entfernen

Klicken Sie neben dem Mitglied auf **Entfernen**. Der Mitgliedschaftsverlauf bleibt zu Nachvollziehbarkeitszwecken erhalten (Eintritts- und Austrittsdatum).

## Mitgliedschaftsverlauf

FitRadarHR bewahrt den vollständigen Verlauf: Ein entferntes Mitglied erscheint weiterhin in Berichten, die während seiner Mitgliedschaftszeit erstellt wurden.

!!! info "DSGVO"
    Übt ein Mitglied sein Recht auf Löschung aus, werden seine personenbezogenen Daten (Name, E-Mail) anonymisiert. Zugehörige Berichte bleiben ohne namentlichen Bezug erhalten.
