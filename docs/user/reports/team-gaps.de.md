# Team-Lückenanalyse

Anders als Fit-Berichte vergleicht die Lückenanalyse **keine Person** mit dem Team. Sie betrachtet allein das Team, um OCEAN-Dimensionen zu erkennen, bei denen die aktiven Profile wenig divers sind.

## Die Analyse erstellen

**Voraussetzung:** Mindestens 2 aktive Teammitglieder haben ihren Big-Five-Fragebogen abgeschlossen (eine Standardabweichung setzt mindestens 2 Messpunkte voraus).

**Schritte:**
1. Klicken Sie auf der Teamseite auf **Lückenanalyse**
2. Die Analyse wird sofort aus den aktiven Profilen berechnet

## Wie wird das berechnet?

FitRadarHR berechnet das **Durchschnittsprofil des Teams** sowie die **Standardabweichung** pro Dimension (dieselbe Berechnung, die auch dem Bericht [Team-Fit](team-fit.md) zugrunde liegt). Eine Dimension mit niedriger Standardabweichung bedeutet, dass sich die aktiven Mitglieder in diesem Merkmal ähneln — das Team ist **homogen**.

Es werden keine neuen Daten erhoben: Die Analyse nutzt die bereits von den Teammitgliedern abgeschlossenen Profile.

## Den Bericht lesen

Die 5 OCEAN-Dimensionen werden immer angezeigt, mit einem Signal:

- **◎ Homogen** — die aktiven Profile liegen bei dieser Dimension nah beieinander
- **◇ Heterogen** — die aktiven Profile sind bei dieser Dimension bereits divers

### Ansatzpunkte für eine künftige Einstellung

Für jede homogene Dimension schlägt ein eigener Abschnitt einen Denkanstoß für eine künftige Einstellung oder einen Teamentwicklungsplan vor.

!!! warning "Das sind keine Empfehlungen"
    Eine homogene Dimension ist an sich kein Problem — es ist eine Beobachtung. FitRadarHR berechnet niemals ein „fehlendes“, einzustellendes Profil; Interpretation und Entscheidung bleiben menschlich.
