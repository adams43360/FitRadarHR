## Elements displayed

| Element | Description |
|---|---|
| **Active positions** | Number of positions with a defined Big Five profile |
| **Teams** | Number of teams created |
| **Pending questionnaires** | Links sent but not yet completed |
| **Recent reports** | Most recently generated fit reports |

## Main navigation

The navigation bar gives access to all sections:

- **Positions** — manage your position sheets and their target profiles
- **Teams** — manage your teams and their members
- **Questionnaires** — track sends and progress
- **Reports** — view and export fit reports
