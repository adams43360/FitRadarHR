# Getting started

Welcome to FitRadarHR. This section guides you from creating an account to your first fit report.

## Getting started steps

1. [Create an account](signup.md) — choose between an organization (B2B) or personal account
2. [Discover the dashboard](dashboard.md) — overview of available features
3. Create your first [position](../positions/create.md) or [team](../teams/create.md)
4. [Send a questionnaire](../survey/send.md) to a candidate or employee
5. Review the [fit report](../reports/index.md)

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A valid email address to create an account
- The email address of the person to be evaluated (to send the questionnaire)
