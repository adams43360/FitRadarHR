# Erste Schritte

Willkommen bei FitRadarHR. Dieser Abschnitt führt Sie von der Kontoerstellung bis zu Ihrem ersten Fit-Bericht.

## Einstiegsschritte

1. [Konto erstellen](signup.md) — wählen Sie zwischen einem Organisationskonto (B2B) oder einem persönlichen Konto
2. [Dashboard entdecken](dashboard.md) — Überblick über die verfügbaren Funktionen
3. Erstellen Sie Ihre erste [Stelle](../positions/create.md) oder Ihr erstes [Team](../teams/create.md)
4. [Fragebogen senden](../survey/send.md) an einen Kandidaten oder Mitarbeitenden
5. [Fit-Bericht](../reports/index.md) einsehen

## Voraussetzungen

- Ein aktueller Webbrowser (Chrome, Firefox, Safari, Edge)
- Eine gültige E-Mail-Adresse zur Kontoerstellung
- Die E-Mail-Adresse der zu bewertenden Person (für den Fragebogenversand)
