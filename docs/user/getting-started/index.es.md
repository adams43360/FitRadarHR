# Primeros pasos

Bienvenido/a a FitRadarHR. Esta sección le guía desde la creación de la cuenta hasta su primer informe de fit.

## Pasos iniciales

1. [Crear una cuenta](signup.md) — elija entre una cuenta de organización (B2B) o personal
2. [Descubrir el panel de control](dashboard.md) — resumen de las funcionalidades disponibles
3. Crear su primer [puesto](../positions/create.md) o [equipo](../teams/create.md)
4. [Enviar un cuestionario](../survey/send.md) a un candidato o colaborador
5. Consultar el [informe de fit](../reports/index.md)

## Requisitos previos

- Un navegador web reciente (Chrome, Firefox, Safari, Edge)
- Una dirección de email válida para crear la cuenta
- La dirección de email de la persona a evaluar (para el envío del cuestionario)
