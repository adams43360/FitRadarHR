# Dashboard

Nach der Anmeldung gelangen Sie zu Ihrem Dashboard — einer Übersicht Ihrer Aktivität.

<!-- screenshot: docs/user/assets/dashboard.png -->
!!! note "Screenshot folgt in Kürze"
    Der Screenshot des Dashboards wird hier ergänzt.

## Angezeigte Elemente

| Element | Beschreibung |
|---|---|
| **Aktive Stellen** | Anzahl der Stellen mit definiertem Big-Five-Profil |
| **Teams** | Anzahl der erstellten Teams |
| **Ausstehende Fragebögen** | Versendete, aber noch nicht abgeschlossene Links |
| **Neueste Berichte** | Zuletzt erstellte Fit-Berichte |

## Hauptnavigation

Die Navigationsleiste bietet Zugriff auf alle Bereiche:

- **Stellen** — Ihre Stellenprofile und deren Zielprofile verwalten
- **Teams** — Ihre Teams und deren Mitglieder verwalten
- **Fragebögen** — Versand und Fortschritt verfolgen
- **Berichte** — Fit-Berichte einsehen und exportieren
