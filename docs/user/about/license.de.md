## Was das konkret bedeutet

✅ Sie können den Code frei einsehen, klonen und studieren
✅ Sie können ihn für Ihren eigenen internen Gebrauch nutzen und anpassen (Ihr Unternehmen, Ihre Organisation)
✅ Sie können ihn zu nicht-kommerziellen Forschungs- oder Bildungszwecken nutzen
✅ Sie können ihn im Rahmen einer Dienstleistung für einen Kunden nutzen, der ihn selbst unter denselben Bedingungen verwendet
✅ Zwei Jahre nach der Veröffentlichung wechselt jede Version automatisch zur **MIT**-Lizenz — ohne dass Sie etwas unternehmen müssen

❌ Sie dürfen ihn ohne Genehmigung nicht nutzen, um Dritten ein kommerzielles Produkt oder eine Dienstleistung anzubieten, die mit FitRadarHR konkurriert — also FitRadarHR ersetzt, mit einem von uns bereits angebotenen Angebot konkurriert oder eine im Wesentlichen ähnliche Funktionalität bietet

Die einzige Einschränkung bei erlaubten Nutzungen: den Urheberrechtsvermerk und einen Link zur Lizenz in weitergegebenen Kopien beizubehalten.

**Kurz gesagt**: FitRadarHR für Ihr HR-Team oder Ihre Teams selbst zu hosten bleibt vollständig frei und kostenlos. Vorbehalten ist lediglich, daraus ohne unsere Zustimmung ein konkurrierendes kommerzielles Produkt oder eine Dienstleistung zu machen.

## Warum es nicht mehr „Open Source“ im strengen Sinn ist

Die offizielle Open-Source-Definition (Open Source Initiative) verbietet jede Einschränkung der kommerziellen Nutzung. Eine Lizenz, die eine Nutzung vorbehält — selbst nur die konkurrierende kommerzielle Nutzung —, ist daher im OSI-Sinn nicht mehr „Open Source“, auch wenn der Code öffentlich und lesbar bleibt. Deshalb sprechen wir von **„Fair Source“** statt „Open Source“: Der Code ist offen, aber die Nutzung ist nicht vollständig uneingeschränkt. Andere bekannte Projekte verwenden dasselbe Modell: Sentry, HashiCorp (vor seiner Übernahme), CockroachDB.
